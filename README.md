# The Flower Within

A pressed-flower scrapbook personality quiz — answer 15 questions and get matched to one of five flower archetypes (Sunflower, Rose, Orchid, Hydrangea, Chrysanthemum).

Live at: https://vanikalyani.github.io/The-Flower-Within/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys automatically to GitHub Pages via GitHub Actions on every push to `main` (see `.github/workflows/deploy.yml`).
